# Data Model: AI/Spec-Driven Book RAG Chatbot Integration

## Entities

### Book Content Chunk
**Description**: A segment of book content that has been processed, embedded, and stored in the vector database with metadata for retrieval

**Fields**:
- `id` (string): Unique identifier for the chunk
- `content` (string): The actual text content of the chunk
- `metadata` (object):
  - `source_path` (string): Path to the original document
  - `title` (string): Title of the section/chapter
  - `page_number` (number): Page number if applicable
  - `section` (string): Section or chapter identifier
  - `created_at` (datetime): Timestamp of creation
- `vector` (array): Embedding vector representation of the content
- `similarity_score` (number): For retrieval results

### Agent Session
**Description**: Represents an active agent session that manages the conversation flow and reasoning process using OpenAI Agents SDK

**Fields**:
- `session_id` (string): Unique identifier for the agent session
- `agent_config` (object): Configuration parameters for the agent
  - `model` (string): The underlying LLM model (Google Gemini 2.0 flash)
  - `temperature` (number): Temperature setting for response generation
  - `max_tokens` (number): Maximum tokens for agent responses
- `created_at` (datetime): Timestamp when the session was created
- `last_activity` (datetime): Timestamp of the last interaction
- `conversation_history` (array): Array of conversation turns

### Agent Task
**Description**: Represents a specific task or reasoning step performed by the OpenAI Agents SDK during the RAG process

**Fields**:
- `task_id` (string): Unique identifier for the agent task
- `task_type` (string): Type of task (e.g., "retrieval", "reasoning", "response_generation")
- `input_context` (object): Input provided to the agent for this task
- `agent_thoughts` (string): Internal reasoning/thoughts of the agent
- `output_result` (object): Result produced by the agent for this task
- `execution_time` (number): Time taken to complete the task in milliseconds
- `status` (string): Current status (e.g., "pending", "completed", "failed")

### User Query
**Description**: A question or request submitted by a user that requires information from the book content

**Fields**:
- `query` (string): The user's question or text input
- `context_mode` (boolean): Whether the query is in contextual mode
- `selected_text` (string): Text selected by the user when in contextual mode (optional)
- `user_id` (string): Identifier for the user (optional, may be anonymous)
- `timestamp` (datetime): When the query was submitted

### Retrieved Context
**Description**: Relevant book content chunks retrieved from the vector database based on semantic similarity to the user query

**Fields**:
- `chunks` (array): Array of Book Content Chunk objects
- `query_embedding` (array): Vector representation of the original query
- `retrieval_params` (object):
  - `top_k` (number): Number of chunks retrieved
  - `similarity_threshold` (number): Minimum similarity score
- `retrieval_time` (number): Time taken for retrieval in milliseconds

### Chat Response
**Description**: The answer generated by the LLM based on the retrieved context and user query

**Fields**:
- `response` (string): The generated answer text
- `source_chunks` (array): IDs of the chunks used to generate the response
- `confidence` (number): Confidence score of the response
- `timestamp` (datetime): When the response was generated
- `context_used` (array): List of context pieces used in generation
- `followup_questions` (array): Suggested follow-up questions (optional)

## Relationships

```
User Query --[triggers]--> Agent Session
Agent Session --[creates]--> Agent Task (retrieval)
Agent Task (retrieval) --[retrieves]--> Retrieved Context
Agent Task (reasoning) --[processes]--> Retrieved Context + User Query
Agent Task (response_generation) --[creates]--> Chat Response
Chat Response --[references]--> Book Content Chunk
Agent Session --[maintains]--> Conversation History
```

## State Transitions

### Chat Session States
1. **Idle**: Waiting for user input
2. **Processing**: Retrieving context and generating response
3. **Response Ready**: Response generated and ready to display
4. **Error**: Error occurred during processing

### Chunk States (in system)
1. **Raw**: Content extracted from source but not yet processed
2. **Chunked**: Content split into appropriate size segments
3. **Embedded**: Vector embeddings generated
4. **Indexed**: Stored in vector database and ready for retrieval

## Validation Rules

### Book Content Chunk
- Content must not be empty
- Vector must have appropriate dimensions (based on embedding model)
- Metadata must include source_path
- Content length should be within configured chunk size limits

### User Query
- Query must not be empty
- Context mode and selected_text must be consistent
- Query length should be within reasonable limits (e.g., 1000 characters)

### Retrieved Context
- Must contain at least one chunk
- Similarity scores should meet minimum threshold
- Number of chunks should match requested top_k parameter

### Chat Response
- Response must not be empty
- Must reference at least one source chunk
- Should indicate when information is not found in book content
